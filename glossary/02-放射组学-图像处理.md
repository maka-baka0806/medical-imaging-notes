## D. 影像组学与图像特征

**影像组学（Radiomics）** `L1` — 从医学图像中高通量提取大量定量特征，把图像变成"可挖掘的数据"。
↳ 一句话：**给图像做群落调查**。

**ROI / VOI（Region / Volume of Interest）** `L2` — 感兴趣区/体积。特征只在 ROI 内计算。

**手工特征 / 深度特征（Handcrafted / Deep Features）** `L2` — 人工定义的数学特征 vs 神经网络自己学出来的向量。

**一阶特征（First-Order Statistics）** `L2` — 只看灰度分布，不看空间关系：均值、方差、偏度、峰度、熵、能量等。
↳ 类比：**只统计"物种多不多、均不均匀"，不管谁挨着谁**。

**GLCOM / GLCM（Gray Level Co-occurrence Matrix，灰度共生矩阵）** `L2` — 统计"相邻（指定方向和距离）的两个体素灰度组合"出现频率。
↳ ⚠️ **论文里写 GLCOM，国际标准写法是 GLCM**，是同一个东西。
↳ 派生特征：Sum Average、Inverse Difference、Info Measure、Contrast、Correlation 等。

**GLRLM（Gray Level Run-Length Matrix，灰度游程矩阵）** `L2` — 统计某个灰度沿某方向连续出现多长。
↳ 最强特征 **Run-Length Non-Uniformity（游程不均匀度）** 来自这里——**直观理解：通气差的区域纹理"长短不一"，健康肺则均匀。**

**GLSZM（Gray Level Size Zone Matrix，灰度区域大小矩阵）** `L2` — 统计相同灰度的连通区域有多大。

**NGTDM（Neighborhood Gray-Tone Difference Matrix）** `L3` — IBSI 里的另一类纹理特征（邻域灰度差）。⚪ 在已读论文中未见明确使用。

**形状特征（Shape Features）** `L2` — 体积、表面积、球形度、紧致度、伸长率等。

**放射组学滤波（Radiomic Filtering）** `L3` — 把 3D 滑窗在器官内逐体素滑动，每个位置算一组特征，于是每个特征变成一张"特征图"。
↳ 关键参数：**窗大小 15×15×15 mm³**（2022 肺论文）、**26×26×26 mm³**（2025 年 4DCT 论文）、**13 个方向取平均**以近似**旋转不变性**。

**体素级 / 区域级放射组学（Voxel-wise / Regional Radiomics）** `L3` — 传统做法是"整块肿瘤一个特征向量"；扩展到**每个体素一个特征向量**，得到空间分辨的信息。

**Habitat Radiomics（栖息地放射组学）** `L3` — 把肿瘤按影像特征分成若干"亚区"分别分析。

**灰度离散化（Gray Level Discretization）** `L3` — 把连续 HU 值分箱，才能算纹理。
- **FBN（Fixed Bin Number，固定箱数）**：固定分成 32/64/128/256 级。
- **FBS（Fixed Bin Size，固定箱宽）**：固定每箱宽度 0.10/0.15/0.22/0.25。
↳ **换离散化参数会改变预后结论**——这是方法学严谨性的关键点。

**IBSI（Image Biomarker Standardization Initiative）** `L2` — 影像组学标准化的国际倡议，规定特征定义与计算流程。
↳ **影像组学界的 MIQE 指南**。

**CERR / IBEX** `L3` — 两个学术界的放射组学工具箱（CERR 基于 MATLAB）。常用于工具箱一致性比对。

**PyRadiomics** `L2` — 最流行的开源放射组学 Python 包。**入门首选工具。**

**剂量组学（Dosiomics）** `L3` — 把**剂量分布**当图像提取特征。

**影像基因组学（Radiogenomics）** `L3` — 把影像特征与基因组/分子标志物联合建模。

**特征稳健性 / 可重复性（Robustness / Reproducibility）** `L3` — 同一病灶换台机器、换个参数，特征值会不会变？**放射组学最被质疑的点。**

**CCC（Concordance Correlation Coefficient，一致性相关系数）** `L3` — 衡量两组测量"是否落在同一条 45° 线上"（比 Pearson 更严格，会惩罚系统偏差）。

**PCC（Pearson Correlation Coefficient）** `L2` — 皮尔逊相关系数，测线性相关。

## H. 图像处理、配准与几何

**图像分割（Segmentation）** `L1` — 给每个体素贴标签。**本质是逐像素分类**。
↳ **脑肿瘤标准三区**：**ET（Enhancing Tumor，增强肿瘤）**、**TC（Tumor Core，肿瘤核心）**、**WT（Whole Tumor，整个肿瘤含水肿）**。**NCR/NET = 坏死与非增强肿瘤核心**。

**勾画 / 轮廓（Delineation / Contour）** `L2` — 医生手工画出边界，是分割的金标准。

**图像配准（Image Registration）** `L2` — 把两幅不同时间/设备/体位的图像对齐。
- **刚性配准**：只有平移旋转。
- **形变配准（DIR, Deformable Image Registration）**：允许局部形变。
- **DVF（Displacement Vector Field，位移矢量场）**：配准的输出，每个体素一个位移向量。
- **多模态配准**：如 MRI ↔ CBCT。

**FEM（Finite Element Method，有限元方法）** `L3` — 把连续体离散成单元求力学平衡。
↳ 用来生成**生物力学合理的形变**作为深度学习配准的监督信号；代价是慢（**>10 分钟/例**）。

**ICP（Iterative Closest Point，迭代最近点）** `L3` — 经典点云/表面配准算法，用于**初始对齐**。

**Jacobian 行列式（det(J)）** `L3` — 形变场局部体积变化率；**det(J) < 0 表示组织"自我折叠"，物理上不可能**。

**自注意力（Self-Attention）** `L3` — 让每个位置根据全局其他位置加权自己。

**隐式神经表示（INR, Implicit Neural Representation）** `L3` — 用网络直接表示连续场（如形变场）。

**速度场与正则化（Velocity Field / Regularization）** `L3` — 把形变建模为连续时变速度场的积分，并约束其平滑性以保拓扑。

**插值（Interpolation）** `L2` — 重采样时的取值方法：**最近邻（nearest-neighbor，不改变标签）**、线性、B 样条。**标签必须用最近邻。**

**滤波（Filtering）** `L2` — 均值滤波、卷积滤波、**小波变换（Wavelet）**（小波 CNN 擅长抓局部细节）。

**Kernel / Sliding Window（核 / 滑窗）** `L2` — "在图像上逐位置滑动的小窗口"，是放射组学滤波与卷积的公共祖先。

**旋转不变性（Rotational Invariance）** `L3` — 特征值不随方向改变。通过**13 个方向取平均**近似做到。
