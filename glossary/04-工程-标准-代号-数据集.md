## I. 软件、数据格式与工程

**Python** `L1` ✅ — 全部深度学习与统计工作的实现语言。

**MATLAB** `L2` ✅ — 矩阵计算与工程语言（MathWorks）。**自研放射组学工具箱的平台**（R2018a → R2023a）。

**TensorFlow** `L2` ✅ — 深度学习框架（示例版本 2.5.0）。

**PyTorch** `L2` ✅ — 深度学习框架（示例版本 1.12.1 及更新）。

**torchdiffeq** `L3` ✅ — PyTorch 上的 ODE 求解器库，Neural ODE 的必需品。

**DeepSphere / HEALPix** `L3` ✅ — 球面卷积实现库 / 球面像素化方案。

**CUDA / GPU** `L2` ✅ — NVIDIA 的并行计算平台。常见显卡：Quadro P5000、RTX 3090、2×A6000、RTX 4090、L20。

**HPC（High-Performance Computing，高性能计算集群）** `L2` ✅ — 多节点集群。3D Neural ODE 曾估计需 **>1 TB 内存**，必须上集群。

**DICOM（Digital Imaging and Communications in Medicine）** `L2` ⚪ — 医学影像与放疗数据的国际标准格式。
↳ 常见扩展：**RTSTRUCT**（勾画结构）、**RTPLAN**（计划）、**RTDOSE**（剂量）。

**NIfTI（.nii / .nii.gz）** `L2` ⚪ — 神经影像常用的单文件格式（BraTS 数据即 NIfTI）。

**SimpleITK / ITK / pydicom / nibabel** `L2` ⚪ — 读写与处理医学图像的通用库。

**nnU-Net（软件）** `L3` ✅ — 既是方法也是可运行的框架（有 Docker 版）。

**MONAI** `L3` ⚪ — 面向医学影像的 PyTorch 生态框架。

**3D Slicer / ITK-SNAP / ImageJ(Fiji)** `L2` ⚪ — 开源影像查看与勾画工具。**入门第一个该装的软件。**

**Git / GitHub** `L2` ✅ — 代码版本管理 / 托管平台。

**conda / pip / 虚拟环境 / Jupyter Notebook** `L2` ⚪ — 环境管理与交互式编程。

**LaTeX / Overleaf / Zotero / EndNote** `L2` ⚪ — 论文排版与文献管理。

**arXiv** `L2` ✅ — 预印本平台。

**可复现性（Reproducibility）三件套** `L2` — **固定随机种子 + 记录超参数 + 保存数据划分**。审稿人最先问的东西。

## K. 模型与方法代号

**Radiomic Filtering（放射组学滤波）** `L3` — 体素级特征地图方法（2022 肺通气论文提出）。

**SPU-Net（Spherical Projection-based U-Net）** `L3` — 球面投影 U-Net：换投影中心 → 多组预测 → **均值 = 分割结果，方差 = 不确定性图**。

**MFC Model（Multi-Feature-Combined）** `L3` — 手工放射组学 + 深度特征 + 临床信息三源融合。

**DR Model（Dual-Radiomics，双放射组学）** `L3` — 手工放射组学 + 深度放射组学并行建模。

**RE-ViT（Radiomics-Embedded Vision Transformer）** `L3` — 把放射组学特征嵌进 ViT 的 patch embedding。

**SCNN（Spherical Convolutional Neural Network）** `L3` — 球面卷积网络，预测 SIMT 正常脑剂量。

**PhysMorph** `L3` — 有限元力学约束 + 深度学习的肝脏 MRI–CBCT 实时配准框架（**代码开源**）。

**HBNODE（Heavy-Ball Neural ODE）** `L3` — 带重球动量的神经 ODE。

**Dual Radiomic and Dosiomic Filtering（双滤波）** `L3` — 影像特征 + 剂量特征联合的滤波框架。

**ACC Analysis** `L3` — 通过逐个移除输入序列来评估各序列对分割的贡献（消融式分析）。

## L. 数据集与公开资源

**VAMPIRE Challenge** `L2` — 肺癌 CT/4DCT + 配对通气参考（Galligas PET / DTPA SPECT）的多中心公开数据集。

**BraTS（Brain Tumor Segmentation Challenge）** `L2` — 脑胶质瘤分割的标杆竞赛数据集（含 ET/TC/WT 标注）。

**TCIA（The Cancer Imaging Archive）** `L2` — 美国 NCI 的公共医学影像库。
↳ **TCIA Lung1**：早期 NSCLC 放疗计划 CT + FDG PET-CT。

**TCGA（The Cancer Genome Atlas）** `L2` — 大规模肿瘤基因组 + 临床 + 影像资源。

**Visible Human Project** `L2` — 标准化人体断层解剖数据。

> **共同意义**：**结果可复现、可比较** —— 等价于生物学里的"模式生物 + 公共数据库"。

## 附：最容易混淆的 8 组词

| 容易混 | 区别 |
|---|---|
| **GLCOM vs GLCM** | 同一个东西（灰度共生矩阵），论文里写 GLCOM，国际标准写 GLCM |
| **两个"蒙特卡洛"** | MCCV = 统计重采样；Monte Carlo 输运 = 粒子剂量模拟 |
| **Dice vs HD95** | 前者看"重叠多少"，后者看"边界差多远"；Dice 高不等于边界准 |
| **灵敏度 vs 特异度** | 找得全 vs 排得准；提高一个通常牺牲另一个 |
| **分割 vs 配准** | 分割 = 贴标签；配准 = 把两幅图对齐 |
| **合成 CT vs 真实 CT** | sCT 是 MRI 用 AI 生成的"假 CT"，只用于剂量计算，不能当诊断 CT |
| **放射组学 vs 剂量组学** | 前者挖影像，后者挖剂量分布 |
| **放射组学 vs 影像基因组学** | 后者把影像特征与基因组数据联合建模 |
