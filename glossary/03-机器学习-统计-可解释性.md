## E. 机器学习与深度学习

**机器学习（Machine Learning, ML）** `L1` — 让程序从数据里学规律，而不是人手写规则。
**经典机器学习（Classic ML）** `L2` — 用人工特征 + 传统分类器（与深度学习对照的说法）。

**监督 / 无监督 / 自监督学习** `L2` — 有标签 / 无标签 / 自己造标签（如遮住图像一部分让自己预测）。

**训练集 / 验证集 / 测试集（Train / Validation / Test）** `L1` — 学 / 调参 / 最终检验。
↳ ⚠️ **测试集只能碰一次**，反复调就是作弊（信息泄漏）。

**标签（Label）与金标准（Ground Truth）** `L2` — 模型要预测的答案。医学里的金标准 = 医生勾画、病理、核医学显像、实测剂量。

**过拟合 / 欠拟合（Overfitting / Underfitting）** `L1` — 背答案 vs 没学会。
**正则化（Regularization）** `L2` — 抑制过拟合：**L1/L2 惩罚、Dropout、早停（Early Stopping）、数据增强**。

**数据增强（Data Augmentation）** `L2` — 旋转、缩放、翻转、加噪声，人为扩充样本。

**类别不平衡（Class Imbalance）** `L2` — 阳性样本远少于阴性，**医学数据常态**。
↳ 对策：**过采样 + 高斯噪声**、**上采样（up-sampling）**、调整损失权重。

**交叉验证（Cross-Validation, CV）** `L2` — 数据轮流做训练/测试。
- **k 折（k-fold）**：分 k 份轮流（常见 5 折、10 折）。
- **LOOCV（Leave-One-Out）**：每次留 1 例做测试。
- **MCCV（Monte Carlo Cross-Validation）**：重复随机划分多次（如 100 折、7:3；或 50 次置换、20% 留出）。

**神经网络 / 深度学习（Neural Network / Deep Learning, DL）** `L1` — 多层可微函数堆叠，用梯度下降学参数。

**CNN（Convolutional Neural Network，卷积神经网络）** `L2` — 用卷积核在图像上滑动提取局部特征。
↳ 相关词：**卷积核（kernel/filter）、步长（stride）、填充（padding）、感受野（receptive field）、池化（pooling）、上采样（upsampling）、批归一化（BatchNorm）、ReLU 激活、Dropout**。

**U-Net** `L2` — 医学分割的"国民网络"：**编码器（下采样抓语义）+ 解码器（上采样恢复分辨率）+ 跳跃连接（skip connection，把细节直接传过去）**。
↳ 变体：**3D U-Net、ResU-Net（残差）、U-Net++、DRU（Deep Residual U-Net）**。

**nnU-Net** `L3` — "no-new-Net"：不设计新结构，而是**根据数据集自动配置** patch 大小、网络深度、归一化、增强策略的框架。
↳ 常见组合：**2D nnU-Net 初分割 + 3D nnU-Net 局部精修**。

**迁移学习（Transfer Learning）** `L2` — 拿预训练模型的权重起步，解决小数据问题。
**Models Genesis（Generic Autodidactic Models）** `L3` — 在大量医学图像上自监督预训练的 **3D U-Net 编码器**；可把图像压成 **512 维深度特征**。

**VGG-16 / VGG-19 / DenseNet-121** `L2` — 三个经典分类骨干网络。

**ViT（Vision Transformer）** `L2` — 把图像切成 patch，用**自注意力（self-attention）**建模 patch 之间的全局关系。
↳ **patch embedding**：把每个 patch 的像素线性投影成向量；**位置编码（positional encoding）**：告诉模型 patch 在哪。
↳ **RE-ViT（Radiomics-Embedded ViT）**：把手工放射组学特征与 patch embedding **平均后融合**再送进 ViT。

**Swin Transformer** `L3` — 用**移动窗口**做分层注意力的 Transformer 变体，兼顾全局与局部。

**LSTM（Long Short-Term Memory，长短期记忆网络）** `L3` — 处理序列的循环网络，靠"门"控制记忆。

**Neural ODE（神经常微分方程）** `L3` — 把网络层间传递看成**连续时间演化**，用 ODE 求解器推进。
- **RK4（四阶 Runge–Kutta）**：经典数值求解器。
- **Adjoint Sensitivity Method（伴随灵敏度法）**：反向传播的省显存做法。
- **HBNODE（Heavy-Ball NODE）**：带"重球动量"的 Neural ODE。
↳ 为什么用它：**能把每个样本"走向结论的轨迹"画出来**——把黑箱变成可观察的动力系统。

**球面卷积 / SCNN（Spherical CNN）** `L3` — 在球面上定义的卷积。
↳ 数学工具：**图拉普拉斯（graph Laplacian）L = D − A**、**谱滤波（把卷积近似成拉普拉斯的多项式）**、**DeepSphere**（实现库）、**HEALPix**（球面像素化方案）。

**KAN（Kolmogorov–Arnold Network）** `L3` — 用可学习的单变量函数替代固定激活函数的新架构；可用 **Jacobi 多项式**构造，并对其主成分建模以提速。

**PSO（Particle Swarm Optimization，粒子群优化）** `L3` — 群体智能优化：一群"粒子"在解空间搜索。
↳ 典型用途：自动寻找**多个模型输出的最佳融合权重**。

**集成学习（Ensemble Learning）** `L2` — 多个模型投票/叠加。

**损失函数（Loss Function）** `L2` — 训练要最小化的目标。
- **BCE（Binary Cross-Entropy，二元交叉熵）**：二分类常用。
- **MSE（Mean Squared Error，均方误差）**：回归常用。
- **Dice Loss**：直接优化重叠度。

**优化器：SGD / Adam / 学习率 / 权重衰减** `L2` — 决定参数怎么更新。
↳ 常见配置：**Adam + lr 1e-3 ~ 1e-5**、**weight decay 1e-5**、**cosine annealing with warm restarts（余弦退火重启）**、**梯度裁剪（gradient clipping）**、**批大小（batch size）**、**训练轮数（epoch）**。

**softmax / logit / sigmoid** `L2` — 把网络输出变成概率/分数。

**特征融合（Feature Fusion）** `L2` — 把不同来源的特征拼在一起：**拼接（concatenation）** 或 **位置编码对齐后融合**。

**z-score 标准化（z-score Normalization）** `L2` — 减均值除标准差，让不同量纲的特征可比。

**多共线性评估（Multi-Collinearity Assessment）** `L3` — 检查特征之间高度相关（冗余），筛出"独立特征"。

**降维（Dimensionality Reduction）** `L2` — 高维压到低维。
- **PCA（Principal Component Analysis，主成分分析）**：找方差最大的正交方向。
- **差异性分析（Dissimilarity Analysis）**：另一种特征选择法（看哪些特征最能区分两组）。

**分类器：LR / SVM / RF / LASSO** `L2`
- **LR（Logistic Regression，逻辑回归）**：线性 + sigmoid，可解释性最好。
- **SVM（Support Vector Machine，支持向量机）**：找最大间隔超平面。
- **RF（Random Forest，随机森林）**：很多决策树投票（如 100 棵树、Gini 不纯度、bootstrap 抽样）。
- **LASSO**：带 L1 惩罚的回归，能把不重要的特征系数压成 0。

**kNN（k-Nearest Neighbors，k 近邻）** `L2` — 找最相似的 k 个样本。

**KDE（Kernel Density Estimation，核密度估计）** `L3` — 不假设分布形状，用核函数平滑估计概率密度。

**蒙特卡洛方法（Monte Carlo Methods）** `L2` — 用大量随机抽样求解问题。
↳ ⚠️ **两个完全不同的"蒙特卡洛"，别混**：
1. **蒙特卡洛交叉验证（MCCV）** ＝ 统计重采样；
2. **蒙特卡洛粒子输运模拟** ＝ 放疗剂量计算（常见软件 Geant4 / TOPAS / EGSnrc / MCNP）。

## F. 统计、验证与评价指标

**Dice 相似系数（Dice Similarity Coefficient, DSC / Dice）** `L1` — `2×A∩B ÷ (A+B)`，0–1。
↳ **就是生态学的 Sørensen 相似性指数**。分割任务的头号指标。
↳ 坑：小目标 Dice 抖动大；必须写清是 ET / TC / WT 哪一个。

**IoU / Jaccard** `L2` — `A∩B ÷ A∪B`，与 Dice 单调对应。

**HD95 / mHD（95% Hausdorff Distance / mean Hausdorff Distance）** `L3` — 预测边界与真实边界之间距离分布的 95 分位 / 平均值（mm）。
↳ **Dice 高但 HD95 差 = 大体对、边界糊。**

**灵敏度 / 特异度 / 准确率（Sensitivity / Specificity / Accuracy）** `L1` — 查得全不全 / 排除得准不准 / 总体对不对。

**ROC 曲线与 AUC** `L2` — 横扫阈值画出的"灵敏度 vs 假阳性率"曲线；AUC 0.5 = 抛硬币，1.0 = 完美。

**混淆矩阵（Confusion Matrix）** `L1` — TP/FP/FN/TN 四格表。

**Spearman 秩相关（ρ）** `L2` — 只看单调关系、不看线性、抗离群值。

**R²、MAE、MAPE、RMSE** `L2` — 回归的拟合优度 / 平均绝对误差 / 平均绝对百分比误差 / 均方根误差。

**PSNR / SSIM** `L3` — 图像相似度指标（峰值信噪比 / 结构相似性）。

**TRE / MSD（Target Registration Error / Mean Surface Distance）** `L3` — 配准精度的两把尺子：标志点误差 / 表面平均距离。

**置信区间 / 标准差 / 显著性检验** `L2` — 常见写法 "mean ± std"；比较两组用 **t 检验**（参数）或 **Kruskal–Wallis ANOVA**（非参数，多组）。

**P 值** `L2` — 在原假设成立下观测到这么极端结果的概率。**不是"结论为真的概率"**（最常见误读）。

## G. 可解释 AI 与不确定性

**可解释 AI（Explainable AI, XAI）** `L2` — 让模型的决定能被人类理解、验证、追责。

**显著性图（Saliency Map）** `L2` — 标出"图像哪些区域对结论贡献大"的热力图。

**CAM 家族** `L3`
- **Grad-CAM**：用梯度加权特征图，最常用的类激活图。
- **Score-CAM**：用分数加权，不依赖梯度。
- **U-CAM**：基于不确定性的类激活图。

**LIME / SHAP** `L3` — 两种"局部解释"方法（局部可解释替代模型 / Shapley 值分解）。
↳ ⚠️ 常见于讨论其**局限**的引言部分，不要误读为"某篇论文用了它们"。

**Integrated Gradients (IG)** `L3` — 沿"从基线到输入"的路径积分梯度，时序模型解释常用。

**LRP（Layer-wise Relevance Propagation，逐层相关性传播）** `L3` — 把输出相关性逐层回传到输入特征，量化每个特征贡献。

**决策场 F 与平衡点（∇F = 0）** `L3` — 在潜空间重构一个"决策场"，用其**局部平衡点**聚合中间状态做预测。**本质是把分类问题几何化、动力系统化。**

**不确定性量化（Uncertainty Quantification, UQ）** `L3` — 让模型输出"我有多确定"。
- **体素级不确定性图（voxel-wise uncertainty map）**：逐像素的"没把握程度"。
- **预测方差法**：换不同"视角"得到多组预测，**方差即不确定性**（SPU-Net 核心）。
- **信息熵（Entropy）**：用熵量化不确定性。
- **Otsu 法聚合**：把不确定性图变成最终分割。
- （概念补充）**aleatoric（数据本身噪声）/ epistemic（模型知识不足）** 是 UQ 的标准二分法。

**Otsu 阈值法** `L2` — 自动选二值化阈值，使类间方差最大。

**时间显著性（Temporal Saliency）** `L3` — 在时序模型里标出"哪些时间步、哪些特征最关键"。
