## 术语笔记（第 1 批 · 20 个）

### 影像与临床

| 术语 | 一句话解释 | 备注 |
|---|---|---|
| **HU（Hounsfield Unit）** | CT 的密度刻度：水 = 0，空气 ≈ −1000，骨 ≈ +1000 | CT 的一切定量分析都建立在这个刻度上 |
| **4DCT** | 按呼吸周期分相位的 CT（通常 8–10 个相位） | 能看到"肺在动"，是肺通气成像的核心数据 |
| **T1ce** | 注射钆对比剂后的 T1 序列，血脑屏障破坏区会强化 | 脑肿瘤分割中，增强肿瘤最关键的一个序列 |
| **FLAIR** | 抑制脑脊液信号的 T2 序列 | 看脑室旁病变、瘤周水肿更清楚 |
| **GTV / CTV / PTV** | 大体肿瘤体积 / 临床靶体积 / 计划靶体积 | **GTV 必须由医生勾画**，这是 AI 研究里的金标准 |
| **DVH** | 剂量-体积直方图，放疗计划的"体检报告" | D2cc、V12Gy 这类指标都从这里来 |
| **SBRT / SRS** | 立体定向体部 / 颅脑放疗，少次数大剂量 | 脑转移瘤常用 SRS |
| **HDR 近距离治疗** | 高剂量率后装治疗，放射源短暂进入体内 | 剂量跌落极陡，计划质量高度依赖经验 |

### 影像组学

| 术语 | 一句话解释 | 备注 |
|---|---|---|
| **Radiomics（放射组学）** | 从图像中高通量提取定量特征，把图像变成可挖掘的数据 | 我把它理解成"给图像做群落调查" |
| **GLCM / GLCOM** | 灰度共生矩阵：统计相邻体素灰度组合的出现频率 | 他论文写 GLCOM，国际标准写 GLCM，是同一个东西 |
| **GLRLM** | 灰度游程矩阵：统计某灰度沿某方向连续出现多长 | 肺通气研究里最强的特征就来自这里 |
| **GLSZM** | 灰度区域大小矩阵：统计相同灰度连通区域有多大 | |
| **一阶特征** | 只看灰度分布（均值、方差、熵），不看空间关系 | |
| **滑窗 / radiomic filtering** | 小立方窗在器官内逐体素滑动，每处算一组特征 | 于是每个特征变成一张"特征图" |
| **旋转不变性** | 特征值不随方向改变 | 通过 13 个方向取平均来近似 |
| **IBSI** | 影像组学标准化的国际倡议，规定特征怎么算、怎么报告 | 相当于 qPCR 的 MIQE 指南 |

### 深度学习

| 术语 | 一句话解释 | 备注 |
|---|---|---|
| **U-Net** | 医学分割的经典网络：编码器 + 解码器 + 跳跃连接 | |
| **nnU-Net** | 自动配置网络结构的医学分割框架 | 先跑通它的官方教程 |
| **迁移学习** | 拿预训练模型的权重起步，解决小数据问题 | Models Genesis 就是预训练好的 U-Net 编码器 |
| **不确定性量化（UQ）** | 让模型说出"我有多确定" | 多重预测的方差可以做不确定性图 |

### 评价指标

| 术语 | 一句话解释 | 备注 |
|---|---|---|
| **Dice 系数** | `2×A∩B ÷ (A+B)`，衡量两个区域重叠度 | **就是生态学的 Sørensen 相似性指数** |
| **HD95** | 预测边界与真实边界距离的 95 分位（mm） | Dice 高但 HD95 差 = 大体对、边界糊 |
| **AUC / ROC** | 判别能力曲线与曲线下面积 | 0.5 = 抛硬币，1.0 = 完美 |
